Virtualizing the message list
How do I virtualize the message list with dynamic row heights?

Use @tanstack/react-virtual and let it measure each row after render:

tsx
const virtualizer = useVirtualizer({
  count: messages.length,
  getScrollElement: () => parentRef.current,
  estimateSize: () => 56,
  overscan: 8,
})

Then two things to watch:

  1. Pass ref={virtualizer.measureElement} to each row so real heights replace the estimate.
  2. When older messages load at the top, keep the scroll anchored so the view doesn’t jump
